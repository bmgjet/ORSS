Setting up a ROM

File > Set-up wizard sets a ROM up for the engine stage by stage, with presets for each stage. File > Change functions adds functions to a ROM you already have, or takes them out, and keeps its tune.

The set-up wizard

A new ROM is offered the wizard as soon as it is made (File > New ROM, from a template or from the skeleton). It can be run again at any time from File > Set-up wizard…. It works on the HTS115 and HTS120 templates and on ROMs built from the skeleton. A setting the ROM does not have is greyed out and marked not in this ROM.

Nothing is written until Apply on the last page, which lists every change first. Everything is applied as one step, so Ctrl+Z undoes the whole set-up.

PageWhat it sets
1 EngineBase maps: keep the ROM's own maps, or start from the fuel and ignition maps of a stock ECU (25 of them, from the D15B and D16 ECUs to the B16A, B18C, H22 and F22, each with its engine and market). Picking one fills in its VTEC point, rev limit and injector size on the pages that follow. VTEC: whether the engine has it and where it engages. Rev limit.
2 Injectors and fuelThe injectors the maps were written for and the ones fitted (every pulse is scaled by the two), the injector lag against battery voltage from a list of 138 injectors, and the overall, cranking, post-start and tip-in trims. It can suggest the cranking and tip-in trims for the new injectors.
3 Sensors and gearboxThe MAP sensor fitted, from the list of sensors (stock, GM, AEM, Omnipower, Motec and more). The gearbox, from 14 Civic, Integra and Prelude gearboxes, sets the gear boundaries the ROM works the gear out from.
4 BoostNaturally aspirated, or turbo / supercharged: how much boost, the fuel added for each bar, the timing taken out for each psi, and a boost cut.
5 OptionsThe ROM's own switches (the ROM options page), ticked as they are now.
6 SummaryEverything Apply will change, and anything that could not be done in this ROM and why.

Base maps from a stock ECU

On an HTS115 or HTS120 ROM, the stock ECU's whole calibration block goes in where it came from, as the established tuning software's base map does. On a ROM built from the skeleton, each map goes to the map here that does the same job (low and high cam fuel and ignition), converted through real units onto this ROM's own breakpoints. This is the same matching that Import maps uses.

MAP sensor

Every load breakpoint of every map, and every setting that is a pressure (a boost cut, a GIO window), is moved to the count that means the same pressure on the new sensor. The ROM also records which sensor is fitted, so the app shows its pressures, and the datalog's MAP, on the right scale. An HTS ROM records it in its MAP preset; a ROM built from the skeleton records it on its MAP sensor page, in two settings the ECU itself never reads. On the Calibration page, Tools > MAP sensor size… does the same swap on its own.

A ROM built from the skeleton reads its maps against a load index that starts at about 0.3 bar on a 3 bar sensor, so very high vacuum shares the first column. The index tops out at about 1.9 bar (12 psi of boost). For more boost than that, look-ups by throttle (Alpha-N) or a larger load index are needed.

Boost

On each fuel and ignition map read against manifold pressure, the load columns are spread up to the boost asked for. The columns up to the air outside are kept as far as there is room, and two to four columns are added above it. Each boost column takes its fuel from the last column below the air outside, plus the percentage for each bar of boost (100 % follows the extra air). Its timing is the same column's less the degrees for each psi. Each fuel map's column multipliers are raised where a boost column needs more than a byte can hold. Fit a MAP sensor that reads the boost (page 3) first.

A start, not a tuneThe wizard gives the engine somewhere sensible to start. Check the fuel on a wideband, and the timing for knock, before using the boost.

Changing the functions of a ROM you have

File > Change functions… rebuilds a ROM made from the skeleton with functions added or taken out, and keeps its tune. For example, VTEC control can be added after the engine is converted to VTEC, or a datalog or launch control added later, without starting a new ROM.

  1. Open the ROM: its build file (the .asm New ROM wrote), or a .bin saved from it.
  2. File > Change functions… shows the New ROM list with the functions the ROM has now ticked in bold, and the same ROM space, module RAM and interrupt time bars and checks.
  3. Tick what to add and untick what to take out, then Rebuild with these.
  4. The ROM is built again, and every setting and map the two builds share is carried across from the ROM that was open: the fuel and ignition maps, the rev limits, and every module's settings. Each goes to wherever the new build put it. A function added starts at its factory settings (modules switched off until you switch them on). A function taken out takes its settings with it.
  5. A build file has its define lines changed in place. A .bin gets a build file written beside it, and is offered to be saved over the old one (kept as .bak, with a definitions file beside it).

Ctrl+Z takes the carried tune back off. Nothing is saved until you save.

A .bin knows what it was built with because every ROM built from the skeleton carries a short build table: a few bytes, one for each function. A .bin made before 0.0.0.5 has no table: open its build file instead. If it was built from an older skeleton, keep its definitions file beside it.

A ROM made from a template such as HTS120 or HTS115 has all its functions in already: switch them on in their pages.

VTEC

The VTEC page has the stock VTEC points, and with VTEC control built in (in Default, or added by Change functions) everything the established tuning software offers:

SettingWhat it does
Enable VTECOff: the solenoid is never switched on (a non-VTEC head, or a conversion not wired yet).
Use these engage pointsOn: the points and conditions on the page decide. Off: the stock points decide, as without the module.
High / low load engageThe engage rpm at or above the high-load throttle, and at or below the low-load throttle, on a straight line in between.
Disengage delayOnce in, VTEC stays in until the rpm is this far under the engage point, so it does not chatter.
Minimum ECT, speed and loadCoolant at least this warm, road speed at least this (above 0 keeps VTEC out at a standstill), manifold pressure at least this.
Disable speed / temp / error checkLeave the road speed or coolant out, or engage even with a sensor fault stored.
Alternative outputRepeat the VTEC solenoid on another output: a VTEC lamp, or a solenoid wired to a different pin.
