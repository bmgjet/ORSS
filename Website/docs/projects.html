Projects and saving

Save the source, save the ROM, or save everything exactly as it is and carry on later.

Saving files

EntryWrites
File > Save Ctrl+SThe source on screen to its file.
File > Save as…The source to a new file — or, picking .bin, the ROM image built from it.
Tools > Save .bin…The ROM as it is now (with every calibration change), checksum right.
Datalog > Save log…The log as CSV.

On a ROM built from the skeleton, the settings the build file keeps (its name and version, the watermark) are written back into it when they change.

Projects

File > Save project… (Ctrl+Shift+S) writes one .zip holding everything as it is:

  • every source (saved or not) and where the editor was;
  • the whole simulated machine — every register, RAM byte, timer, peripheral and the engine — so it resumes mid-instruction;
  • the ROM with its changes, the definitions and the formulas;
  • the breakpoints (on and off), held RAM bytes, Hit trace;
  • Tuner mode, the table on screen and how it was viewed;
  • the loaded datalog and where it was in it.

Open the .zip with File > Open to carry on where you were.

Auto save

Every few minutes (Settings > General) a restore point is written. File > Restore last auto save opens the newest.

Clear project

File > Clear project closes the ROM and lets everything go — sources, definitions, machine state, hits, datalog frames — leaving the program idle and small.
