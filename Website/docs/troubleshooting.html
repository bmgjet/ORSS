Troubleshooting

What to check when something does not work. The Debug tab has everything the program did, with errors in red — look there first.

The datalog will not connect

  • The right port? Unplug the cable and see which port goes away (Settings > Emulator & datalog lists them).
  • Does the ROM stream a datalog? A stock ROM does not. HTS, a skeleton ROM with a datalogging module, and most tuned ROMs do.
  • The protocol: leave it on auto-detect, or try Detect layout for an unknown ROM.
  • An echo on the line means the cable's wiring, not a slow ECU. Some cables need Raise DTR and RTS (Settings > Emulator & datalog > Serial timing); a longer pause between request and answer helps a slow adapter.
  • The key on, the ECU powered: an ECU that just saw power takes a moment; the program retries.

Readings jump about

Turn on Smooth values: spikes on the line (a 28 rpm reading between two at 6000) are dropped and the rest blended; the raw frame is kept as it came.

The ECU will not boot, and every output strobes

That is the ECU resetting over and over. On a ROM built from the skeleton:

  • Make sure it was made with version 0.0.0.4 or later. Earlier skeletons let the stock clock self-test (FEAT_STOCK_SELFTEST) fail when some modules were added, which resets the ECU; rebuild the ROM with this version.
  • Check the checksum: save it with Tools > Save .bin… (which keeps it right) rather than an outside tool.
  • Run it in the simulator first, from Reset, and look for a trap (BRK) in the Debug tab.
  • The chip: the right type (27C256 / 29C256), fully programmed and verified, in the right way round; a 64 KB chip needs the ROM in the half the board reads (see the Bin tool).

A module does nothing

Every module starts switched off. Open its page on the Calibration tab, set it up and tick its Enable. Some need extra hardware wired in: a wideband, an ethanol sensor, a switch on an input.

Two outputs fight

The Problems tab lists any two functions switched on and set to drive the same ECU pin, and a pin a built-in stock function drives too. Pick another output for one of them.

A value will not go higher

Values are held to what the ECU and the engine can use (rpm settings to 12,500, advance to 50°, duty to 100 %…). The editor shows the range when you point at the box. See safe limits.

The program is slow on an old laptop

Turn on Low performance mode (Settings > General) and use Tuner mode for tuning: the workbench's panels are let go and the datalog comes first.

The emulator will not upload

Check its port in Settings > Emulator & datalog, then Connect in the Emulator menu. Validate reads it back and compares; the dot blinks orange while a lost link is being rebuilt.
